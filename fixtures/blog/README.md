# fixture blog

Repo mínimo para el spike de la Fase 0. Se commitea como archivos planos;
para usarlo como repo git de verdad:

    git init -b main
    git add -A
    git commit -m "fixture: blog"

`README.md` es a propósito un archivo no relacionado con la colección:
ensúcialo (`echo cambio >> README.md`) y verifica que el commit hecho
desde Folio no se lo lleva.
